# NurseInsight——护理不良事件智能根因分析（RCA）与质控看板

面向临床护士长的轻量级智能 RCA 辅助工具。输入不良事件描述后，系统按"人机料法环（4M1E）"框架构建提示词并调用大语言模型，自动生成结构化根因分析与整改建议；结果支持人工审核修正，并汇入多维度质控看板，可一键导出规范 Word 质控报告。

## 功能模块

- **数据管理与录入**：模拟数据生成（100 条）与 Excel 导入、字段校验、缺失值提示
- **智能根因分析**：4M1E 框架提示词 + JSON 结构化输出约束，DeepSeek API 调用，非不良事件输入自动拦截
- **人机协同闭环**：AI 结果可逐条编辑修正，修正记录写入本地 `user_feedback.json` 供人工复核
- **可视化质控看板**：科室分布、事件类型占比、严重程度构成，支持科室与时间筛选联动
- **一键导出报告**：`python-docx` 生成规范 Word 质控报告（含数据概览、主要发现、典型案例整改建议、图表）

## 运行环境

Python 3.10 及以上（开发环境为 Python 3.12 / Windows 11，同样支持 macOS）。

## 运行步骤

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

启动后浏览器自动打开 `http://localhost:8501`。

> 请在本目录下执行上述命令。Streamlit 读取的是当前工作目录下的 `.streamlit/config.toml`（深色主题配置），换目录启动会回退成浅色主题。

## API Key 配置

系统按以下顺序获取 DeepSeek API Key，**界面上不显示密钥内容**：

1. 本地 `config.json`（优先）
2. Streamlit Secrets（`DEEPSEEK_API_KEY`，适用于云端部署）
3. 侧边栏手动输入（仅保存在当前会话）

本地配置文件请参照 `config.example.json` 创建：

```json
{
  "DEEPSEEK_API_KEY": "在这里填入你的DeepSeek API Key"
}
```

未配置密钥时，数据管理、质控看板、Word 报告导出等功能仍可正常使用，仅 AI 分析会提示"请先配置 API Key"。
